## 关键差异

| 维度 | 改动前 | 改动后 |
|------|--------|--------|
| **反馈次数** | 每个 Agent 只能反馈 1 次 | 每个 Agent 可以无限轮次修改 |
| **反馈作用** | 传递给下一个 Agent | 让当前 Agent 重新生成 |
| **用户体验** | 一次性输出，无法调整 | 迭代优化，直到满意 |
| **退出条件** | 输入反馈后自动进入下一步 | 回车确认后才进入下一步 |

## 实现细节

### 核心循环逻辑

```python
for step in range(1, 5):  # 4 个 Agent
    iteration = 0
    
    while True:  # 无限轮次循环
        iteration += 1
        
        # 运行 Agent
        result = await run_agent(step, feedback_history)
        
        # 显示结果
        print_result(result)
        
        # 获取用户反馈
        feedback = get_user_feedback()
        
        if feedback == "":
            # 用户满意 → 退出循环，进入下一个 Agent
            break
        else:
            # 用户不满意 → 记录反馈，继续循环
            feedback_history.append({
                "agent": current_agent_name,
                "feedback": feedback
            })
```

### 反馈历史管理

每次用户输入修改意见后，会追加到 `state.feedback_history`：

```python
[
    {"agent": "能力画像专家", "feedback": "请补充我的 Python 项目经验"},
    {"agent": "能力画像专家", "feedback": "技术深度评估偏低，我有 5 年经验"},
    {"agent": "市场匹配引擎", "feedback": "用户选择的转行方向: AI · 算法工程师"},
    {"agent": "路径规划架构师", "feedback": "学习周期太长，能否压缩到 6 个月"},
]
```

Agent 在每次运行时都能看到完整的反馈历史，从而逐步优化输出。

## 断点续跑兼容性

Checkpoint 结构保持不变，新增的 `feedback_history` 会被保存：

```json
{
  "session_id": "abc123",
  "completed_steps": [1, 2],
  "next_step": 3,
  "feedback_history": [
    {"agent": "能力画像专家", "feedback": "请补充 Python 经验"},
    {"agent": "能力画像专家", "feedback": "技术深度偏低"}
  ],
  "results": { ... }
}
```

恢复会话时，所有反馈历史会被加载，Agent 3 可以看到 Agent 1 的多轮修改记录。
